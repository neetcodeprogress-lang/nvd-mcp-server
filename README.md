## What this is
- An MCP server that lets AI assistants look up Common Vulnerabilities and Exposures from the 
National Institute of Standards and Technology's National Vulnerability Database.

## Tools
Tool | What it answers 
:--|:--
`search_cves`| "What's out there for this product?"
`get_cve` | "Tell me everything about CVE-2024-21762"
